================================================================
 WAVGAT / WT32-ETH01-Evo – Hardware Wiring Guide
 Based on: SAS 6.0x + DM9051 Ethernet (onboard, SPI) + MAX3232 + Optocoupler
================================================================

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 1. DM9051 – ONBOARD (không cần module rời)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

 DM9051NP được tích hợp sẵn trên PCB ETH01-Evo, nối với ESP32-C3
 (module WT32C3-S5) qua SPI nội bộ. Traces cố định – KHÔNG đấu dây thêm.

 Chân nội bộ (chỉ để tham khảo firmware – xác nhận qua 3 nguồn độc lập,
 KHÔNG có trong datasheet header chính thức vì là trace nội bộ):
 ─────────────────────────────────────────────────────────
 SPI_MOSI │ GPIO10  │ ESP32-C3 → DM9051
 SPI_MISO │ GPIO3   │ DM9051 → ESP32-C3
 SPI_CLK  │ GPIO7   │ Clock
 SPI_CS   │ GPIO9   │ Chip Select (active LOW) – trùng chân strapping BOOT,
                       nhưng CS mặc định idle-high khớp đúng yêu cầu boot=1
 INT      │ GPIO8   │ Interrupt (active LOW) – cũng là chân strapping
 RESET    │ GPIO6   │ Hardware reset (RSTB)

 Kết nối ra ngoài: RJ45 onboard → dây Ethernet LAN trực tiếp.
 Hỗ trợ PoE qua chân POE+/POE- (cần module tách nguồn PoE riêng).

 2. GPIO strapping & bị chiếm – KHÔNG sử dụng cho việc khác
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

 Strapping pin chính thức (ESP32-C3): GPIO2, GPIO8, GPIO9
   - GPIO9 phải là "1" lúc boot để chạy SPI Boot Mode (chế độ chạy
     firmware bình thường); kéo xuống 0 lúc reset → vào chế độ nạp.
   - GPIO8/GPIO9 đã dùng nội bộ cho DM9051 (INT/CS) – an toàn vì mức
     mặc định của chúng khớp đúng yêu cầu boot.
   - GPIO2 được nhà sản xuất dùng làm TXD chế độ AT command – tránh
     dùng lại cho mục đích khác nếu không chắc chắn.

 GPIO khác không nên đụng:
   GPIO 3, 6, 7, 10 : DM9051 SPI (nội bộ, không lộ ra header)
   GPIO 1, 3        : Debug/burning header (TXD0/RXD0 - UART0, nạp qua USB-TTL rời)

 GPIO an toàn để dùng (Universal IO, không strapping, không multiplex):
   GPIO 0, 18, 19

 3. RS232 Interface: ESP32-C3 ↔ MAX3232 ↔ Optocoupler ↔ Slot Machine
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  [ETH01-Evo]          [Optocoupler]      [MAX3232]        [Slot DB9]
  GPIO18 (UART1 TX) ──► 6N137 input ────► T1IN (TX) ─────► DB9 Pin 2 (RXD)
  GPIO19 (UART1 RX) ◄── 6N137 output ◄── R1OUT (RX) ◄──── DB9 Pin 3 (TXD)
                                                             DB9 Pin 5 (GND) [ISOLATED]

 Vị trí trên connector chính (30 pin, theo datasheet chính thức):
   GPIO18 → pin 21
   GPIO19 → pin 22

 MAX3232 Capacitors (100nF ceramic each):
   C1: C1+ ↔ C1-
   C2: C2+ ↔ C2-
   C3: V+  ↔ GND
   C4: V-  ↔ GND

 Power domains (CRITICAL – no shared ground):
   Domain A (Safe):     ESP32-C3 3.3V / GND  ──► LED side of optocoupler
   Domain B (Isolated): Mornsun B0505S-1W (5V in / 5V isolated out)
                        → powers MAX3232 + phototransistor side of 6N137

 4. UART Configuration (SAS 9-bit emulation)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

 UART port  : UART1 (SAS) | UART0 (debug, qua USB-TTL rời gắn header nạp)
 Baud rate  : 19200
 Data bits  : 8
 Stop bits  : 1
 Parity     : Toggled per-byte at runtime in firmware
              - Address byte → UART_PARITY_MARK  (bit9 = 1)
              - Data byte    → UART_PARITY_SPACE (bit9 = 0)

 SAS DB9 pinout (DTE, RS232):
   Pin 2 : RXD  (Machine transmits → ESP32 receives via GPIO19)
   Pin 3 : TXD  (ESP32 transmits  → Machine receives via GPIO18)
   Pin 5 : GND  (ISOLATED – Domain B)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 5. Nạp firmware (KHÔNG có USB tích hợp)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

 Board này KHÔNG có cổng USB – phải dùng bộ chuyển USB-TTL rời cắm vào
 header nạp/debug 6 chân: EN, GND, 3V3, TXD(GPIO1), RXD(GPIO3), IO0.

 Chế độ nạp (download mode) của board này dùng GPIO9 kéo xuống GND lúc
 reset (KHÁC với GPIO0 như đa số board ESP32 khác) — theo datasheet
 chính thức. Có thể cần giữ nút BOOT thủ công nếu board không có mạch
 auto-reset cho chân GPIO9.

 6. Power Supply
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

 Component                    │ Supply              │ Current (max)
 ─────────────────────────────┼─────────────────────┼──────────────
 WAVGAT ETH01-Evo              │ 5V hoặc 3.3V (chọn 1)│ 500 mA
 DM9051 (onboard)              │ tích hợp, 3.3V LDO  │ tích hợp trong 500mA trên
 Optocoupler 6N137 (LED side)  │ 3.3V (Domain A)     │ 10 mA each
 MAX3232 RS232 side            │ 5V isolated (Domain B, Mornsun) │ 200 mA

 Decoupling caps near MAX3232: 100nF ceramic + 10µF electrolytic trên 3.3V rail.
